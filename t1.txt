'In LangChain’s ecosystem, **Deep Agents** are a “batteries-included” way to build LLM agents that can **plan**, **use tools**, **spawn subagents**, **manage context via a filesystem**, and optionally **persist long-term memory** for complex, multi-step work. The `deepagents` package is a standalone SDK built on top of **LangChain agents** and uses the **LangGraph runtime** for things like durable execution, streaming, and human-in-the-loop workflows.  \nSources: Deep Agents overview (https://docs.langchain.com/oss/python/deepagents/overview), LangChain overview comparison (https://docs.langchain.com/oss/python/langchain/overview)\n\nKey built-in capabilities called out in the docs include:  \n- **Planning & task decomposition** via a built-in `write_todos` tool (https://docs.langchain.com/oss/python/deepagents/overview)  \n- **Context management** via filesystem tools like `ls`, `read_file`, `write_file`, `edit_file` (https://docs.langchain.com/oss/python/deepagents/overview)  \n- **Subagent spawning** via a built-in `task` tool for isolating context (https://docs.langchain.com/oss/python/deepagents/overview)  \n- **Long-term memory** by integrating LangGraph’s Memory Store (https://docs.langchain.com/oss/python/deepagents/overview)\n\nWhen to use them (per the docs): if you want agents that handle **complex, multi-step tasks**, **large context**, **delegation to specialized subagents**, and **memory across conversations/threads** (https://docs.langchain.com/oss/python/deepagents/overview).'
